05Вопросы

Вопросы и ответы: малые архитектурные формы

01Делаете ли по эскизу художника?
Да. Принимаем эскиз или 3D-модель, разрабатываем конструктив с закладными, изготавливаем и доставляем. Шеф-монтаж — опция.
02Какой металл лучше для улицы?
Нержавеющая сталь — для зеркальных и полированных форм, бронза — для литья с патиной, алюминий — для лёгких объёмных форм, чугун — для классических элементов.
